# Corpus

This directory holds the canonical test and flagship corpora.

- `manifest.json` — versioned corpus manifest (`vole.audio.corpus.v1`).
- `generated/` — deterministic corpus objects generated by the implementation
  (never by hand; regeneration must reproduce identical hashes).

Current state: **EMPTY_DRAFT**. No corpus content claims are made until the
flagship corpus is frozen in Phase M (target: ~100 diverse SampleObjects,
several minutes of material, 44.1/48/96/192 kHz, mixed representation classes,
noise/adversarial controls).

Rules:

1. The corpus is frozen before the flagship performance court runs; it is
   never tuned after results exist.
2. Every object in a frozen corpus is bound by content identity (SHA-256).
3. `manifest.json` lists objects and the corpus hash; `vole-audio corpus
   verify` checks every listed object against its hash.
