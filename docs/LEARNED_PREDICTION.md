# LEARNED PREDICTION — semantics

## A hypothesis, not truth

An **Executable Learned Hypothesis** is a deterministic executable description
proposed by fitting/search:

```text
H_Theta : reconstructed exact history -> predicted current intrinsic sample
R       : X - H_Theta                       (exact residual, i32)
X_hat   : H_Theta + R                       (must equal X, bit for bit)
```

It is never the "true cause" of a signal, a recovered physical mechanism, a
privileged latent reality, or proof that the source was generated by the learned
process. It earns its place only as a measured point on the representation
Pareto frontier.

## Three semantic families

### Finite-field (`LearnedFiniteField`, `LearnedBlockLocal`)

```text
H_t     = F_Theta(X_hat[t-R .. t-1], C_t)
X_hat_t = sat_i32(H_t + R_t)
```

Closed-loop over already reconstructed history. With `block_frames == None`
this is a single causal stream; seeking replays from frame 0. With
`block_frames == Some(B)` history resets at each block boundary, so each block
is independently materializable and random access touches only the target block.

### Stateful (`LearnedStateful`)

```text
H_t     = sat_i32(round_shift(out_b + W_out · S_t, 12))
X_hat_t = sat_i32(H_t + R_t)
S_{t+1} = act(round_shift(rec_b + W_rec · S_t + W_in · X_hat_t, 12))
```

**This order is normative.** The state update consumes the *reconstructed*
current sample, never an encoder-only source sample the decoder does not yet
possess. This is closed-loop exact predictive decoding. Seeks load the nearest
canonical checkpoint and replay deterministically.

### Transfer (`LearnedTransferOperator`)

```text
H_t     = F_Theta(S, C)[t]
X_hat_t = sat_i32(H_t + R_t)   with   X_hat == target
```

`S` is a **declared dependency**. The learned operator competes against simple
analytic relationships (identity, gain, affine, delay, FIR, IIR, convolution,
static polynomial, piecewise-linear, moving average) and never treats the
source as free: standalone and marginal economics are reported separately.

## Closure precedes observation (O.8)

For learned intrinsic state:

```text
X_O = C_rho(H_Theta, R)          first
P_q = T_q(X_O, A, q)             second
```

`T(H) + T(R)` is **not** implemented, because exact commutation has not been
proven for resampling, interpolation, pitch/rate transforms, reverse, loop
mapping, saturation, quantization, channel conversion, spatial rendering,
sparse overwrite, transform residuals, or endpoint packing. A fused
implementation is allowed; the semantic ordering is not.

## What a learned candidate may not do

* replace the literal fallback;
* change `u1/v1`;
* bypass exact closure;
* claim acceptance from an approximation that "sounds good";
* be selected by a weighted score rather than Pareto dominance.
